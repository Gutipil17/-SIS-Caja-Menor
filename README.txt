SIS GASTOS v1.9.3

MÓDULOS COMPLETAMENTE INDEPENDIENTES
- Caja Menor
- Viáticos

Cada módulo conserva por separado saldos, movimientos, recibos, soportes, historial, Excel, PDF y copias de seguridad. Los datos anteriores se migran a Caja Menor.

SEGURIDAD Y DATOS
- Las librerías necesarias están incluidas localmente para operar sin depender de terceros.
- El repositorio no contiene nombres personales ni matrículas preconfiguradas.
- Las plantillas Excel fueron limpiadas de nombres, identificaciones, tarjetas y gastos históricos.
- La exportación bloquea informes sin movimientos, fuera de periodo, con saldo negativo o por encima de la capacidad del formato.
- Los datos siguen guardándose localmente y sin cifrar en el navegador. Esta versión es para pruebas internas controladas, no sustituye una plataforma corporativa con usuarios, roles y base de datos segura.
